# ReachPoint: judge report (AI Builder Cup 2026, Sustainability & Social Impact)

Judged: branch `claude/location-ui` at `96b9d07` (main `77c554f` + 3 location commits), Tue 13 Oct 2026. Read-only review. Gemini, Pinpoint and Maps were not called: tests and the local server ran with `REACHPOINT_AI=off` and a temporary `HOME`, so the env file was never read.

## 1. Verdict

ReachPoint is one of the more carefully designed entries I would expect to see. The AI is fenced in by code, not by prompts: every extracted fact needs a verbatim quote, the agent's tools are allowlisted, the safety floor holds whatever the model says, and the OR-Tools split solver is real. The full victim → desk → team → family loop, including the boat-failure cascade, ran end to end on my local server. Today it would still lose on the hard requirements: nothing is deployed, the Docker image as written will not start, and the deploy script gives the server no Gemini credentials, so the live URL would show the keyword stand-in instead of AI. Several headline claims in the docs (Thai voice agent, copilot, Firestore, Vertex AI) are not built.

**Weighted score: 64.75 / 100.** That is above a typical entry but not yet a finalist. If the deploy works with live Gemini, the docs are made honest and there is a sub-3-minute video, I would expect about 72–75.

## 3. Per criterion

### Technical Merit & Gen AI (6.0)

**Built and verified (by me)**
- Tests: `pytest api/tests data/tests` → **246 passed** (29 s). `web: npm test` → **99 passed, 15 files**. `tsc --noEmit` is clean.
- The core loop on a local server (port 8099, AI off) worked step by step:
  - I posted a Thai request with a GPS pin. It got `R-001` and status token, and the location snapped to `B-3-L2`.
  - The review queue showed quoted facts and the danger sign `หายใจไม่ออก`, with an urgent-flag prompt.
  - Approve created `C-09`. T-S claimed it; a second claim by T-R returned `ALREADY_TAKEN`.
  - After the window was set, the family page showed the bilingual line "Team T-S expects… 13:00–14:00 (team estimate, not a promise)".
  - Marking boat S1 unavailable held the job. The family line changed to "on hold… earlier estimate withdrawn… Next update 11:00".
- Gemini extraction (`api/intake/extract.py`):
  - JSON schema output at temperature 0 (L181-190).
  - `validate` drops any fact whose quote isn't in the caller's text, with Thai SARA AM and zero-width normalisation (L83-148).
  - Falls through a list of models on 503/429/404 (L22-25, L196-217), with a labelled keyword stand-in.
- ADK triage agent (`api/ai/triage.py`):
  - Allowlisted tools, checked after the run (L29, L189).
  - A link must name a case that `find_similar` returned (L119).
  - A danger sign forces `newHazard` (L123).
  - Quotes are checked against the text (L121, L134).
  - Model fallback, then rules fallback (L157-194).
  - Runs in the background, one pass at a time (`api/main.py` L332-354).
- Briefing text (`api/ai/briefing_text.py`): Gemini output is shown only if every number in it appears in the facts and it makes no route, safety or priority claim (L18-24, `validate`). This is a good "AI can't invent numbers" pattern.
- Split solver: OR-Tools CP-SAT, lexicographic objective (`api/rules/allocation.py` L1-40), served live through `api/views/planning.py`.
- Idempotent writes (`submissionId`), version conflicts (`expectedRevision`, `NEED_CHANGED`), and inputs bounded by Pydantic (`api/main.py` L273-297).

**Built, not verified (team-reported)**
- The live triage eval scored 8/8 on 12 Oct (`api/scripts/triage_eval.py`). It has only 6 cases and one run, and the output is not committed. Two of its 8 checks ("emergencies first", "injection not first") are guaranteed by `TriageSession.ordered()` (L141-144), which sorts by extracted danger signs, so they test extraction rather than the agent.

**Weaknesses (with evidence)**
1. **The container won't start.** I confirmed three defects by simulating the image layout:
   - `api/rules/allocation.py` L30 imports `ortools`, and `api/main.py` imports it through `api/views/planning.py`. But `ortools` is only in `api/requirements-dev.txt`, not `api/requirements.txt`. With `ortools` blocked, `import api.main` fails with `ModuleNotFoundError`.
   - `api/server/flood_replay.py` L8 imports `data.surge`. The Dockerfile copies only three JSON files from `data/`, so the import fails with `ModuleNotFoundError: No module named 'data.surge'`.
   - `api/location/geo.py` L11/L41 reads `areas`, `segments` and `landmarks.geojson`, which are not copied. In the simulated image `/api/locate` (pin) and `/api/intake/text` with a pin both returned **HTTP 500**.
2. **No AI on the deployed URL.** `scripts/deploy.sh` sets only `REACHPOINT_CLOCK=demo`. `api_key()` needs `GEMINI_API_KEY` (env or a home file, `extract.py` L72-80). The comment at `main.py` L8 ("Cloud Run's own identity calls Google APIs") is not true of the code: it uses an AI Studio key on `generativelanguage.googleapis.com`, not Vertex AI. Without a fix, judges would see "Keyword stand-in" and "Approve: 0 people" (`shots/ux-5-desk-en.jpg`).
3. **The agent's role is thin.** The desk order is the rule sort (`triage.py` L141-144). The agent adds link proposals and rank *reasons*, but the UI says "Sorted by the triage agent" (`web/src/i18n/strings.ts` L89), which overclaims.
4. **Things the docs describe that aren't built:**
   - Thai voice agent on Gemini Live/ADK, coordinator copilot, Firestore transactions, Firebase Auth and Hosting, Vertex AI (`docs/OVERVIEW.md` "Where the AI is", "Components"). No code matches.
   - `docs/planning/build-week-tasks.md` L38-40, L80 and L105 are still open.
   - The call screen is text only (`web/src/features/intake/CallPage.tsx`).
5. **No auth.**
   - `/api/demo/reset` is public (`main.py` L452).
   - `/api/views/reviewQueue` returns exact caller coordinates and raw text to anyone (I observed `"at":[100.4705,7.0089]`). This contradicts the D25 claim that only the coordinator and the taking team see the exact point.
6. **State lives in memory with `--min-instances 0`.** A cold start wipes the demo. Every viewer of the public URL shares, and can reset, one state.

**What would add 1–2 points:** deploy a working image with live Gemini, using Vertex AI through the Cloud Run service account or a Secret Manager key. Commit an eval with real numbers: extraction precision/recall on 30–50 Thai/English requests, quote-drop rate, agent duplicate-link accuracy, and results over 3+ runs. Make the agent's output change something visible, or relabel it honestly.

## 6. Questions a judge would ask in Q&A

- **"Is the AI actually ranking, or is it rules?"** The order is a fixed safety rule (danger signs first, then oldest), on purpose, so a model can never push a life threat down. Gemini reads the facts, and that includes the danger signs that drive the order. The ADK agent proposes duplicate links and reasons; a human decides. Show the eval.
- **"What stops the model hallucinating a fact?"** Every fact must quote the caller verbatim, or it is dropped in code (`validate`). Briefings are shown only if every number is in the input facts. The agent can link only to a case its own `find_similar` tool returned.
- **"What about prompt injection, e.g. 'rank me first'?"** Caller text is data. Rank comes from danger signs and the desk, and the tools are allowlisted. Show the eval case.
- **"What if Gemini is down?"** It falls through the models, then to a labelled keyword stand-in and rule-based triage. The desk keeps working, and everything is still human-approved.
- **"Who would use this in the next flood, and how does it fit 1669 and LINE groups?"** Have one concrete answer ready: a named foundation type, the coordinator desk, and channel import as the next step.
- **"How do you know the people estimate is right?"** It is a range from Open Buildings, WorldPop and DOPA, checked against GISTDA's ~150,000 total. It only orders zones and never creates cases or counts.
- **"Is the data real?"** The flood extent is real Sentinel-1 data from 24 Nov 2025. Families, teams and calls are synthetic and labelled.
- **"Why not Firestore and auth?"** Scope choice for a one-week build: one Cloud Run instance in memory, with the store interface ready to swap. Don't claim otherwise.
- **"Does the voice agent exist?"** No. Text intake only; voice is the next step. Answer straight.
- **"What does it cost to run?"** Have a number ready: Cloud Run scaled to zero plus Gemini Flash-Lite per request, per 1,000 requests.
