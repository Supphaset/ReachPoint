# 0003 — Map emphasis requested

Date: 2026-10-11 (Asia/Bangkok).
Status: Accepted requested capability/emphasis; detailed approach, final MVP and implementation remain unapproved.
Human approval reference: user message, “I want it to have map as well,” after review of the product proposal and static wireframes.

## Decision and rationale

Retain and emphasize the household needs map request R4. The product proposal must make geographic context visible alongside flood evidence, assessment gaps and volunteer/response information. A map helps relate area evidence and case/task locations; it does not establish flood depth, victim counts or response feasibility by itself.

## Proposed approach and alternatives

A central Situation map plus linked Contact Center location review and Response map/list views are proposed in map experience (removed 2026-10-11; in git history). A separate fourth map page and a list-only coordinator surface remain alternatives; neither is selected. No provider, basemap, framework, live location service or source integration is accepted.

## Consequences and unknowns

Product detail, PRD and wireframe guide are updated; two expanded static map drawings supplement the prior pack. All displayed geography is synthetic. Real data access, licensing/cost, source cadence, measurement reference, privacy and accessibility remain unresolved. This request authorizes design review artifacts, not application implementation, paid features or deployment.
