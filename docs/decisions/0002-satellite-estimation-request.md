# 0002 — Satellite estimation requested capability

Date: 2026-10-11 (Asia/Bangkok).
Status: Accepted requested capability; approach, final MVP and implementation remain unapproved.
Human approval reference: user message, “add settle light image for the people estimation for the number of house,” interpreted in the ongoing area-assessment discussion as satellite imagery for building and population estimation.

## Decision and rationale

Record R9: satellite-informed building and population exposure estimates. This provides context for areas absent from incoming requests. Building detections, residential use, household counts, modeled population and current presence/needs stay separate. Imagery alone does not establish who needs help.

## Evidence and alternatives

Google Open Buildings and WorldPop are researched candidates (U5–U6 in the source register), not selected providers. Alternatives include existing footprint/population layers, locally supplied authoritative data or a custom detector. Existing data is proposed first; no technical selection has been accepted.

## Consequences and unknowns

Requirements, prototype PRD and assessment research are updated. Actual local data, licensing, dates, quality, population assumptions, validation, cost and effort remain open. The existing workload estimate excludes this extension. No screens, data ingestion, model, infrastructure or paid service has been implemented or authorized.
